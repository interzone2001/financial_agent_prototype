Financial Agent Graph

The LangGraph StateGraph built by build_graph() in backend/app/graph.py. It has 7 nodes and 11 edges. One graph serves both request types: guard_in reads mode and sends each run down the report path or the chat path.

report path chat path conditional edge (chosen by after_guard_in)

How a run moves

Report · POST /api/report

  1. guard_in checks the ticker exists at the SEC. An unknown ticker raises TickerNotFoundError, which returns a 404 before any spend.
  2. market_node and filings_node run in parallel. Each one catches its own failures and writes a warning, so one failed source still gives a partial report.
  3. compose builds the Report and resets chat history.
  4. guard_out drops claims that give advice or have uncited or unknown citations, and adds a warning for each.

Chat · POST /api/chat

  1. run_chat returns a 409 if the thread has no stored report yet.
  2. guard_in refuses injection attempts. A refusal goes straight to guard_out.
  3. router (Haiku) picks market, filings, both or off_topic.
  4. chat_answer calls one or both agents. For both, it concatenates the answers under headings. off_topic returns a polite refusal without calling an agent.
  5. guard_out runs the advice check (regex plus Haiku) and checks filings citations, then appends the turn to history.
